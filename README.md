# Margin & GST Calculator

A web-based tool to dynamically calculate prices, discounts, GST rates, and margin values in a tabular format.

## Features
- **Price Calculation**: Calculate discounted prices automatically.
- **GST Modes**: Supports multiple GST options (5%, 12%, 18% inclusive/exclusive).
- **Margin & Total Calculation**: Auto-calculates final totals with quantity multipliers.
- **Responsive Table**: Easy-to-use dynamic row table structure.

## How to Use
1. Enter the base **Price**.
2. Input the **Discount %** if applicable.
3. Select the required **GST Mode**.
4. Set the **Margin** and **Quantity**.
5. The final **Total** will be calculated automatically.
